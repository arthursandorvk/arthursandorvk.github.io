About

My research centers on cryptographic access control for outsourced data: how to let resource-constrained devices enforce fine-grained, revocable policies over cloud-stored data without trusting any single party. My recent work introduces a decentralized, lightweight server-aided revocable ABE scheme for mobile cloud computing — eliminating the fully trusted key generation center, supporting unlimited data users, and replacing time-based revocation with state-triggered updates, published in IEEE Transactions on Dependable and Secure Computing.

Earlier work spans decentralized multi-authority attribute-based encryption, proxy re-encryption, medical-data access control, location privacy, and blockchain security — including smart-contract vulnerability detection, selfish-mining attacks, and gateway-based blockchain constructions for IoT.
